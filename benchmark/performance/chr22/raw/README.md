# Raw chr22 Pilot Outputs

Raw benchmark outputs are generated by `../run_chr22_pilot.sh` into timestamped directories under this `raw/` directory.

They are intentionally excluded from Git because a full pilot run contains per-guide PAF, stderr, command, and metric files that are bulky relative to the summary artifacts.

The final pilot raw outputs remain on MooseFS in this working tree at:

```text
benchmark/performance/chr22/raw/pilot_final_20260731T163824Z/
```

A checksum manifest for that run is stored outside the ignored raw tree at:

```text
benchmark/performance/chr22/raw_manifest.tsv
```
