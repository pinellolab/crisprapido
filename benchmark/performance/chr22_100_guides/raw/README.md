# Raw chr22 100-Guide Benchmark Outputs

Raw performance outputs are generated by `../run_chr22_100_guides.sh` into timestamped directories under this `raw/` directory.

They are intentionally excluded from Git because a full run contains per-guide PAF, stderr, command, and metric files.

The retained final run on MooseFS is `pilot_100_fallback_20260801T180205Z`. A checksum manifest for that run is stored outside this ignored tree as `../raw_manifest.tsv`.
